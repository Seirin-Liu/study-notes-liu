# 知序 · 本地错题工作台

知序把错题和笔记整理成可查找、复习、打印的本地题库，支持语文、数学、英语、物理、化学和生物。把试卷照片、PDF 或文字发给本地 Codex，它可以识别题干和选项，核对答案与解析，处理题图，生成结构化记录并保存到题库。网页负责编辑、筛选、随机复习和打印。公式由项目内置的 KaTeX 与 mhchem 排版，网页运行无需安装依赖或配置 API 密钥。

## 启动工作台

需要 Node.js 18 或更新版本。将项目完整解压或克隆到固定目录。

- macOS 双击 `start-local.command`。也可在项目目录运行 `sh start-local.sh`。
- Windows 双击 `start-local.cmd`。
- Linux 在项目目录运行 `sh start-local.sh`。

启动后打开 [本机工作台](http://127.0.0.1:4318/)。终端启动时，保留服务窗口即可继续使用，按 Ctrl+C 停止。若 macOS 无法双击运行，直接使用终端命令。端口冲突时，在项目目录运行 `node server.mjs --port 4320`，再访问 [备用端口](http://127.0.0.1:4320/)。

### 在局域网使用

先停止占用同一端口的服务，再在项目目录运行 `node server.mjs --lan`。同一网段的手机或电脑可打开终端显示的地址，和本机共用题库。默认只监听本机。局域网模式下无需登录即可查看和编辑，请在信任的网络内开启。多个网卡时，将本机实际 IPv4 地址传给 `--lan`，例如 `node server.mjs --lan 192.168.1.10`。

## 录入错题与笔记

**交给 Codex**。在 Codex 中打开项目根目录，发送资料并指定题号、学科和整理要求。Codex 会核对可辨认的题干、选项、配图和批注，生成答案与解析。能确认卷名和题号时一并填写来源。简单的装置图、流程图可准确重绘，复杂图和实物照片可裁切、转正并清晰化。

> 把附件第 5、6、9 题录入数学错题本，专题选「数列」。核对原题和答案，写清推导中最容易跳步的地方。需要的图插到对应位置，保存后运行题库校验。

**网页手动录入**。点击「录入新题」或题卡上的「编辑」，设置条目类型和专题。错题答案可选文本、判断或单选。笔记在「题目」写标题，将正文填入「解析」。题目和解析工具栏支持插入公式和题图，以及加粗、下划线和黑、红、蓝三色。可在「本题图片」中裁切、转正、转灰度和调整对比度。文字草稿可在同一浏览器重新打开编辑页时恢复，未保存的新图片需要重新添加。

在 Codex 生成批次文件后，在项目目录运行以下命令。更新已有 ID 时，在第一条命令末尾加 `--replace`。打开的网页约每两秒检查题库的文件版本。

```sh
node scripts/add-question.mjs work/batch.json
node scripts/validate.mjs
```

## 筛选、复习和打印

1. **筛选题目**。进入学科页，默认显示「错题」和「全部时间」。用关键词、来源、专题、掌握状态或上传时间缩小范围。可以逐题勾选，也可以用「全选当前结果」。
2. **按上传日期选题**。点击「按日期选择」，可在日历上跨月选多个日期。确认后时间筛选切回「全部时间」，所选日期上传的错题和笔记会追加到本次打印。手机端在「更多」里找批量操作与打印预览。
3. **随机复习**。从单科或全部学科抽取 5、10、15 或 20 道错题。判断和单选题选择后显示正误，文本题可展开答案与解析自行核对。
4. **打印或保存 PDF**。默认使用 B5 双栏紧凑排版，可切换 A4、单栏，并分别开关答案、解析和备注。点击预览纸面可放大并用左右两侧翻页，点击题图可查看大图。默认按勾选顺序打印。可用「自动调整顺序」减少页末留白，再检查预览。点击「导出 PDF」打开打印对话框，选择打印或保存为 PDF。纸张尺寸与预览一致，缩放选 100%，关闭浏览器页眉页脚。

## 本地数据和备份

题库实际写入 `data/subjects/<学科>.json`。专题字典是 `data/topics.json`，题图在 `data/assets/`，打印设置在 `data/settings.json`。内容修改前的历史快照在 `data/history/`，只改打印设置时不生成题库快照。迁移或备份请复制整个 `data/` 目录。代码提交只包含应用及文档，个人题库、题图和历史留在本机。

英语词表可交给 Codex 增量整理。它从未标记题目的题干和选项挑选较难单词，与现有词表去重。成功写入词表后，把已检查的题标为 `vocabularyProcessed: true`，供下次跳过。

## 开发与验证

浏览器加载由 `src/app/` 生成的 `dist/app.js`。修改前端逻辑后重建。新增题目使用现有录入脚本。项目共享题目示例见 [examples/new-question.json](examples/new-question.json)。

```sh
npm run build
node --test tests/*.test.cjs tests/*.test.mjs
node tests/chemistry.cjs
node scripts/validate.mjs
```

公式组件验证排版语法，化学校验脚本可检查支持的反应式是否守恒。答案、推导和实验条件仍需要逐题核对。组件许可证位于 [dist/vendor/katex/LICENSE](dist/vendor/katex/LICENSE)。
