# 项目目标与验收标准

本文记录用户确认的长期目标。后续本地 Codex 开发、录题和修复均以此为依据；本文描述目标，不表示功能已经全部实现。当前进度见 `docs/IMPLEMENTATION_STATUS.md`。

## 核心使用场景

项目运行在用户自己的电脑上。本地 Codex 打开并接管整个项目文件夹。用户每次直接在 Codex 对话中发送试卷照片，指定题号、选项、学科或错题分类；Codex 识别原题、核对答案和解析，生成程序支持的数据，直接写入项目本地文件。用户无需复制 JSON、手工录入网页，也无需为应用配置识图 API。

浏览器负责整理和打印本地题库：左侧选择学科，在当前学科内按上传时间、错题分类筛选，并勾选本次需要的题目；右侧实时展示且仅展示本次所选题目的打印预览。最终纸质打印/PDF 应与预览内容、顺序和分页一致。

## 职责与文件

- 本地 Codex：理解照片、裁取必要图像、核查学科知识、生成结构化数据、写文件并验证。题目资料默认只在本地项目保存，不自动提交 GitHub。
- 本地服务：读取题库与图片，安全保存、历史备份、冲突检测；无需调用外部模型服务。
- 前端：学科与分类浏览、日期筛选、选择题目、实时预览、打印及备份导出。
- `data/questions.json`：现有题库唯一主文件。新增题用已有录入脚本，不能整库替换或通过改页面代码录题。
- `data/assets/<question-id>/`：规划的持久题图目录，必须随本地备份一起保留。图片协议落地前不得向当前题库写入无效图片字段或引用。
- `work/`：照片处理和批量录入的中间文件，不作为持久图片地址。

## 分类、时间与选择规则

1. 学科为数学、物理、化学、生物，使用现有英文标识。错题分类先沿用 `topic` 专题，如“数列”“硫”“受力分析”；不要另造与专题重复的分类字段。用户以后提出“计算错误”等错误原因维度时再独立设计。
2. `createdAt` 表示首次录入这道错题的时间，作为“上传时间”；不使用照片拍摄时间、文件修改时间或最后编辑时间。`updatedAt` 表示最后修改时间。按题目记录筛选，不必保留整张原卷。
3. 日期按用户本机时区显示和筛选，起止日均包含；支持只填开始/结束、清空和默认新到旧排序。旧题有合法 `createdAt` 就沿用，缺失值需一次性稳定迁移并说明，禁止每次读取重置。
4. 筛选与打印选择独立。单题勾选、全选当前结果、清空选择；所选题按当前排序打印，显示数量。切换学科清空选择，避免混入别科；同学科改变筛选保留选择并提示隐藏的已选数量。
5. 未选择题目时显示空预览并禁用打印，不得自动把所有筛选结果当成已选。刷新无需恢复临时选择，删除或外部同步后移除失效的选中 id。

## 题目、公式和图像

题干、指定选项、原题号、答案、完整解析、备注需分明，不能遗漏关键条件或擅自扩大题号范围。数学/物理公式使用 LaTeX，化学式和方程式使用 mhchem；核查守恒和反应条件，不能以语法通过代替学科正确。

无法用公式准确表达的装置图、几何图、曲线、表格或示意图，由 Codex 从照片中裁取并校正方向，去除无关边缘，保存为清晰的本地图像。能准确重绘且能逐项核对时可生成静态图；不得虚构线条、数据、刻度或文字。看不清的关键标注先询问用户。优先保留题目原图，不用生成式图像代替需要精确表达的科学事实。

图片必须有与所属题目、位置、说明对应的结构化引用，支持题干、选项、解析中的指定位置；仅在正文末尾追加所有图片不算完成。建议采用文本/公式与图片块交错的数据结构，最终字段先在 schema、录入、读写、编辑、导入导出、预览中统一实现，再在 QUESTION_FORMAT.md 中公布。题图不能引用临时工作路径、外网地址或另一台电脑的绝对路径。必须验证路径在资产目录内、文件存在、格式及尺寸有效。旧版纯文本题库仍可读写，保存时不得丢图。

## 打印要求

默认 B5、双栏、紧凑但清晰，保留 A4、单栏、答案显隐和答案下划线。分页应基于实际字体、公式、图片加载后的尺寸；打印前等待字体和图片就绪，缺图或公式错误必须明确提示并阻止输出残缺内容。

普通题尽可能整体放置；长题允许在段落间续页，并标注题号及“续”。公式和图片不得从中切断。图片按栏宽等比缩放，图注紧随，禁止拉伸、裁掉关键内容或遮住文字。宽图或复杂图在双栏不可辨认时，提示切换单栏或采用经验证的跨栏方案。不得用过度缩小字体掩盖溢出。隐藏答案时同时隐藏解析、答案图与备注中的解答内容，保留题干图和适当答题空间。

## 端到端验收

- 本地 Codex 收到含公式和必要图像的卷子照片，只录入用户指定题目，自动保存后浏览器同步，重启服务数据仍在。
- 四科切换，专题与日期条件组合工作；修改旧题不改变首次上传日期。
- 勾选不同题、全选当前结果、改变筛选和切换学科后，右侧预览严格符合上述选择规则，打印不夹带未选题。
- B5 双栏与 A4 单栏分别检查短题、跨页长题、长公式、宽图、竖图、图注和隐藏答案；预览与 PDF 均无截断、缺图、重叠、意外空页。
- 缺图、非法路径、坏 JSON、冲突写入有明确错误，现有题库不被清空；备份恢复和导入导出不丢公式、图像与时间信息。
