# 实现状态与开发顺序

以下基于本次检查的仓库代码。这次更新记录用户目标和本地 Codex 操作规范，没有把待开发功能标记为已经实现。

| 能力 | 当前状态 | 相关代码 / 后续工作 |
| --- | --- | --- |
| 本机启动、离线公式与字体 | 已有 | `server.mjs`、启动脚本、`dist/vendor/` |
| macOS 启动入口 | 已有，待真机确认 | `start-local.command`，兼容 Homebrew PATH；终端可用 `sh start-local.sh`，支持自定义端口及 Node 版本检查 |
| JSON 题库、录题命令、同步、快照和冲突检测 | 已有 | `lib/store.mjs`、`scripts/add-question.mjs` |
| 学科、专题、关键词、掌握状态筛选 | 已有 | `dist/app.js`、`dist/index.html` |
| B5/A4、单双栏、答案显隐、长公式分页 | 已有 | `dist/print-preview.js`，仍需图像场景回归 |
| 首次录入/最后修改时间 | 已有基础 | schema 保留 `createdAt`/`updatedAt`，缺失时按读取时间补值；需严格校验及稳定迁移 |
| 按上传时间筛选与排序 | 待实现 | 增加日期区间和排序 UI、日期语义及组合筛选 |
| 逐题勾选和本次打印集合 | 待实现 | 当前预览直接使用全部筛选结果；增加独立选中 id 集合及数量提示 |
| 原题号独立字段 | 待实现 | 当前可写入题干，新增字段时贯通规范、读写和显示 |
| 持久题图与图文混排 | 待实现 | 当前 schema 归一化会丢弃未知字段，公式渲染会转义 HTML；不能直接写图片字段或 Markdown |
| 图片就绪后的分页、缺图检查 | 待实现 | 当前分页仅将公式作为不可拆分节点，须增加图片节点和异步测量 |
| 资产本地访问与完整导入导出 | 待实现 | 当前服务仅提供 `dist/` 静态文件；增加受限资产路由、PNG/JPEG 等 MIME、备份和打包支持 |

建议开发顺序：

1. 固化上传时间和原题号协议，补兼容迁移；完成日期筛选、排序、逐题选择及右侧预览。
2. 实现图片/内容块协议，贯通 schema 校验与 normalize、LocalStore、录入、编辑、导入导出，保证保存后资产引用不丢失；完成受限本地资产路由。
3. 完成图文混排、加载等待、图片缩放和分页；同步更新格式说明、真实图片示例与离线打包脚本。
4. 按 `PRODUCT_GOAL.md` 的端到端场景验收，增加日期边界、跨筛选选择、图像持久化、路径越界与真实 PDF/截图验证。保留现有公式、快照、冲突测试。

每次完成实现后更新此表。规划字段示例不得放进可直接录入的 `examples/new-question.json`，直到当前程序真正支持。
