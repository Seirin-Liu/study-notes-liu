# 实现状态与开发顺序

以下基于当前仓库代码。图片协议已有基础实现；复杂图文分页和实体打印仍需验证。

| 能力 | 当前状态 | 相关代码 / 后续工作 |
| --- | --- | --- |
| 本机启动、离线公式与字体 | 已有 | `server.mjs`、启动脚本、`dist/vendor/` |
| macOS 启动入口 | 已有，待真机确认 | `start-local.command`，兼容 Homebrew PATH；终端可用 `sh start-local.sh`，支持自定义端口及 Node 版本检查 |
| JSON 题库、录题命令、同步、快照和冲突检测 | 已有 | `lib/store.mjs`、`scripts/add-question.mjs` |
| 学科、专题、关键词、掌握状态筛选 | 已有 | `dist/app.js`、`dist/index.html`；题目类别统一用较宽专题归档，筛选区默认显示两行，更多类别可展开 |
| B5/A4、单双栏、答案显隐、长公式分页 | 已有 | `dist/print-preview.js`，仍需图像场景回归 |
| 首次录入/最后修改时间 | 已有基础 | schema 保留 `createdAt`/`updatedAt`，缺失时按读取时间补值；需严格校验及稳定迁移 |
| 按上传时间筛选与排序 | 已实现 | 起止日期均包含，按本机时区解释 `createdAt`，默认新到旧；可与类别、状态、关键词组合 |
| 逐题勾选和本次打印集合 | 已实现 | 单题勾选、全选当前结果、清空选择；隐藏的已选题保留并提示，切换学科清空，预览仅显示已选题 |
| 原题号独立字段 | 待实现 | 当前可写入题干，新增字段时贯通规范、读写和显示 |
| 持久题图与图文混排 | 已实现基础 | `images` 文件名协议与 `[[image:...]]` 位置标记；题目列表和打印预览均按标记紧跟对应文字显示，按栏宽等比缩放；浏览器编辑文字保留图片 |
| 图片就绪后的分页、缺图检查 | 已实现基础，待复杂图片回归 | 预加载图片、缺图报错、整图分页；宽图及复杂长题仍需实物打印检查 |
| 资产本地访问与完整导入导出 | 部分实现 | 受限资产路由和本地打包包含 `data/assets`；浏览器 JSON 导入导出已移除，备份需复制整个 `data/` |

后续工作：

1. 固化原题号协议，并对缺失或非法 `createdAt` 做稳定迁移。
2. 对宽图、竖图、长题和答案图做实际打印及 PDF 验证，完善跨页排版。
3. 如需网页上传题图或跨设备导入，增加包含图片资产的完整备份格式。当前通过本地 Codex 录图和复制整个 `data/` 备份。
4. 按 `PRODUCT_GOAL.md` 的端到端场景继续验收，保留现有公式、快照、冲突与题图路径测试。

每次完成实现后更新此表。规划字段示例不得放进可直接录入的 `examples/new-question.json`，直到当前程序真正支持。
